# Atlas Suite

Atlas Suite is a modular toolkit for building reproducible data-processing pipelines. It bundles a typed configuration layer, a plugin system and a lightweight runtime that can execute the same pipeline locally, on a cluster or in CI.

The catalog record tracks the public face of the project: the hosted demo, the documentation portal and, when it exists, the source repository.
