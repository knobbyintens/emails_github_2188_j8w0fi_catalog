# Beacon CLI

Beacon CLI is the command-line companion for the Beacon incident toolkit. It provides log tailing, alert routing checks and a small set of deployment helpers that teams run from a terminal.

The catalog record links the documentation portal and the hosted service; the source link must point at the maintained repository under the maintainer's own hosting account.
